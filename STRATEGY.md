## Введение

### Что это за стратегия?

**Short Breakdown on Weak Assets** — это momentum-стратегия для торговли в шорт (ставка на падение цены). Она ищет активы, которые:

1. **Слабее рынка** — падают сильнее, чем Bitcoin
2. **Пробивают поддержку** — цена закрывается ниже важного уровня
3. **Подтверждают пробой объёмом** — много продавцов

### Почему именно эта стратегия?

| Преимущество | Объяснение |
|--------------|------------|
| **Следование за трендом** | Мы не пытаемся поймать разворот, а присоединяемся к движению |
| **Объективные критерии** | Всё измеримо: RS, объём, уровни — нет субъективности |
| **Автоматизируемость** | Чёткие правила позволяют создать бота |
| **Фильтрация шума** | Множество фильтров отсекают ложные сигналы |

### Для какого рынка?

- **Криптовалютные фьючерсы** (ByBit, Binance Futures)
- **Таймфрейм**: 1 минута (скальпинг/интрадей)
- **Инструменты**: Mid-cap альткоины (не BTC, ETH, SOL — они слишком стабильны)

## Теоретическая база

### Психология рынка за стратегией

#### Почему слабые активы продолжают падать?

```
                    ПСИХОЛОГИЯ УЧАСТНИКОВ РЫНКА
                    
    Рынок растёт (BTC +2%)     |     Актив падает (ALT -1%)
    ─────────────────────────────────────────────────────────
    
    Лонгисты:                  |     Лонгисты:
    "BTC растёт, куплю ALT!"   |     "Почему ALT не растёт?!"
           ↓                   |            ↓
    Покупают → цена должна     |     Паника → начинают продавать
    расти, но НЕ растёт!       |     
           ↓                   |            ↓
    "Что-то не так с ALT..."   |     Стоп-лоссы срабатывают
           ↓                   |            ↓
    Продают → давление вниз    |     Каскад ликвидаций
```

**Ключевой инсайт**: Если актив не растёт, когда весь рынок растёт — значит, крупные игроки его продают. Это **информационное преимущество**.

#### Почему пробой поддержки важен?

```
Price
  │
  │     ══════════════════  ← Сопротивление (потолок)
  │    ╱                  ╲
  │   ╱    ЗОНА БАЛАНСА    ╲
  │  ╱                      ╲
  │ ══════════════════════════ ← Поддержка (пол)
  │                         │
  │                         │ ← ПРОБОЙ! Цена уходит ниже
  │                         ▼
  │                    Новая зона
  └────────────────────────────── Time
```

**Поддержка** — это уровень, где раньше появлялись покупатели. Когда цена пробивает поддержку:

1. **Стоп-лоссы лонгистов** срабатывают → дополнительное давление вниз
2. **Шортисты** видят подтверждение и открывают позиции
3. **Старая поддержка** становится новым сопротивлением

### Концепция Relative Strength (RS)

**Relative Strength** — это сравнение динамики актива с бенчмарком (BTC).

```
         СИЛЬНЫЙ АКТИВ                    СЛАБЫЙ АКТИВ
         
    BTC: +3%                          BTC: +3%
    ALT: +5%                          ALT: -1%
    ─────────                         ─────────
    RS = +2% ✅                       RS = -4% 🔴
    
    Актив сильнее рынка               Актив слабее рынка
    → НЕ шортим                       → ШОРТИМ при пробое
```

**Почему RS важен?**

- RS показывает **внутреннюю слабость** актива
- Слабый актив при падении BTC упадёт **ещё сильнее**
- Это как "попутный ветер" для нашего шорта

## Ключевые индикаторы

### 1. Relative Strength (RS)

#### Формула

```
RS = (Изменение актива за N минут, %) - (Изменение BTC за N минут, %)
```

#### Пример расчёта

```
Дано:
- BTC цена 60 минут назад: $42,000
- BTC цена сейчас: $43,050
- SOL цена 60 минут назад: $142.00
- SOL цена сейчас: $140.15

Расчёт:
BTC Change = ((43050 - 42000) / 42000) × 100 = +2.5%
SOL Change = ((140.15 - 142.00) / 142.00) × 100 = -1.3%

RS(SOL) = -1.3% - (+2.5%) = -3.8%
```

**Интерпретация**: SOL слабее BTC на 3.8% — это сильный сигнал слабости.

#### Пороговые значения

| RS | Интерпретация | Действие |
|----|---------------|----------|
| > 0% | Актив сильнее BTC | Не шортим |
| 0% до -3% | Нейтрально/слабо | Не шортим |
| -3% до -5% | Слабый актив | **Шортим при пробое** |
| < -5% | Очень слабый | **Приоритетный шорт** |

### 2. Уровень поддержки (Support Level)

#### Метод определения: Fractal Low

**Фрактал** — это локальный минимум, окружённый более высокими минимумами.

```
Цена
  │
  │         *           
  │       *   *         
  │     *       *   *   
  │   *           *   * 
  │ *               *   
  │       [F]           ← Фрактальный минимум (Support)
  │                     
  └─────────────────────── Время
      -2  -1  0  +1  +2   ← Позиция свечи относительно фрактала
```

#### Условие фрактала

```
Low[i] < Low[i-2]  AND
Low[i] < Low[i-1]  AND
Low[i] < Low[i+1]  AND
Low[i] < Low[i+2]
```

#### Пример

```
Свеча #1: Low = $141.50
Свеча #2: Low = $141.20
Свеча #3: Low = $140.80  ← Кандидат на фрактал
Свеча #4: Low = $141.10
Свеча #5: Low = $141.40

Проверка свечи #3:
- $140.80 < $141.50? ✅
- $140.80 < $141.20? ✅
- $140.80 < $141.10? ✅
- $140.80 < $141.40? ✅

→ Свеча #3 — фрактальный минимум, Support = $140.80
```

### 3. Объём (Volume)

#### Зачем нужен объём?

Объём подтверждает **серьёзность** движения:

```
        ПРОБОЙ С ОБЪЁМОМ              ЛОЖНЫЙ ПРОБОЙ
        
    │                              │
    │   ▄▄▄▄                       │   ▄▄▄▄
    │   ████ Support               │   ████ Support
    │   ████═══════                │   ████═══════
    │   ████      ↓                │   ████  ↓
    │ ▄▄████▄▄▄▄▄▄█▄▄              │   ████  █
    │ ██████████████               │   ████  █ (малый объём)
    │     ↑                        │        ↑
    │ Высокий объём                │ Нет подтверждения
    │ = Реальные продажи           │ = Вероятен откат
```

#### Формула Volume Ratio

```
Volume Ratio = Текущий объём / Средний объём за 20 свечей
```

#### Пример расчёта

```
Последние 20 свечей (объём в монетах):
[120, 95, 110, 88, 102, 115, 98, 105, 92, 108,
 100, 112, 96, 104, 118, 90, 106, 94, 100, 107]

Средний объём = Сумма / 20 = 2060 / 20 = 103

Текущая свеча: объём = 185

Volume Ratio = 185 / 103 = 1.8x
```

#### Пороговые значения

| Volume Ratio | Интерпретация | Score |
|--------------|---------------|-------|
| < 1.5x | Слабый объём | Сигнал отбрасывается |
| 1.5x - 2.0x | Нормальный | +10 баллов |
| 2.0x - 3.0x | Высокий | +20 баллов |
| > 3.0x | Экстремальный | +30 баллов |

### 4. Close Position (Позиция закрытия)

#### Зачем это нужно?

Показывает, **кто контролирует свечу** — покупатели или продавцы.

```
        СВЕЧА ПРОДАВЦОВ           СВЕЧА С ОТКУПОМ
        
        │                              │
   High │────┐                    High │────┐
        │    │ Тело                    │    │
        │    │                         │    │
        │    │                         │    │ Хвост (wick)
        │    │                         │    │
  Close │────┤ ← Закрытие внизу        │    │
        │    │                         │    │
    Low │────┘                    Close│────┤ ← Закрытие вверху
        │                          Low │────┘
        │                              │
   ClosePos = 0.1 (10%)           ClosePos = 0.7 (70%)
   → Продавцы доминируют          → Покупатели откупили
   → ХОРОШИЙ сигнал               → ПЛОХОЙ сигнал
```

#### Формула

```
Close Position = (Close - Low) / (High - Low)
```

#### Пример

```
High  = $142.50
Low   = $140.00
Close = $140.25

Close Position = (140.25 - 140.00) / (142.50 - 140.00)
               = 0.25 / 2.50
               = 0.10 (10%)

→ Закрытие в нижних 10% свечи — очень сильный сигнал
```

#### Пороговые значения

| Close Position | Интерпретация | Действие |
|----------------|---------------|----------|
| > 30% | Был откуп (buyback) | Сигнал отбрасывается |
| 10% - 30% | Продавцы контролируют | Сигнал проходит |
| < 10% | Сильное давление продаж | +10 бонусных баллов |

### 5. Funding Rate

#### Что такое Funding Rate?

На фьючерсном рынке **Funding Rate** — это периодическая плата между лонгами и шортами для привязки цены фьючерса к спотовой цене.

```
Funding Rate > 0 (положительный)     Funding Rate < 0 (отрицательный)
─────────────────────────────────    ────────────────────────────────
Лонги ПЛАТЯТ шортам                  Шорты ПЛАТЯТ лонгам
                                     
→ Много лонгов в рынке               → Много шортов в рынке
→ Перекупленность                    → Перепроданность
→ Шорт более выгоден                 → Риск short squeeze!
```

#### Зачем нам это?

**Anti-Squeeze фильтр**: Если funding слишком отрицательный, рынок переполнен шортами. Любая позитивная новость вызовет **short squeeze** — резкий рост из-за закрытия шортов.

```
                    SHORT SQUEEZE
                    
    Цена
      │                    ╱╲
      │                   ╱  ╲
      │                  ╱    ╲ ← Резкий рост
      │        ─────────╱      
      │       ╱                 
      │──────╱                  
      │                         
      └─────────────────────────── Время
              ↑
         Все шорты
         закрываются
         одновременно
```

#### Пороговые значения

| Funding Rate | Интерпретация | Действие |
|--------------|---------------|----------|
| < -0.015% | Crowded short | **Сигнал отбрасывается** |
| -0.015% до 0% | Нейтрально | Сигнал проходит |
| 0% до 0.01% | Слегка лонговый | Сигнал проходит |
| > 0.01% | Много лонгов | **+20 бонусных баллов** |

## Система фильтров

### Пайплайн фильтрации

Каждый сигнал проходит через **7 последовательных фильтров**. Если хоть один не пройден — сигнал отбрасывается.

```
┌─────────────────────────────────────────────────────────────┐
│                    ВХОДЯЩАЯ СВЕЧА                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ ФИЛЬТР 1: Достаточно данных?                                │
│ (минимум 30 свечей для актива и BTC)                        │
└─────────────────────────────────────────────────────────────┘
                              │ ✅
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ ФИЛЬТР 2: RS < -3%?                                         │
│ (актив слабее BTC минимум на 3%)                            │
└─────────────────────────────────────────────────────────────┘
                              │ ✅
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ ФИЛЬТР 3: Funding Rate >= -0.015%?                          │
│ (нет переполненности шортами)                               │
└─────────────────────────────────────────────────────────────┘
                              │ ✅
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ ФИЛЬТР 4: Volume Ratio >= 1.5x?                             │
│ (объём выше среднего)                                       │
└─────────────────────────────────────────────────────────────┘
                              │ ✅
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ ФИЛЬТР 5: Close Position <= 30%?                            │
│ (нет сильного откупа)                                       │
└─────────────────────────────────────────────────────────────┘
                              │ ✅
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ ФИЛЬТР 6: Найден уровень поддержки?                         │
│ (фрактальный минимум за последние 60 минут)                 │
└─────────────────────────────────────────────────────────────┘
                              │ ✅
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ ФИЛЬТР 7: Close < Support?                                  │
│ (цена закрытия ниже уровня поддержки)                       │
└─────────────────────────────────────────────────────────────┘
                              │ ✅
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    РАССЧЁТ SCORE                            │
│              (если Score >= 50 → СИГНАЛ)                    │
└─────────────────────────────────────────────────────────────┘
```

### Статистика фильтрации

Примерное распределение (из 1000 свечей):

| Фильтр | Проходит | Отсеивается |
|--------|----------|-------------|
| Достаточно данных | 95% | 5% |
| RS < -3% | 15% | 80% |
| Funding | 14% | 1% |
| Volume > 1.5x | 5% | 9% |
| Close Position | 3% | 2% |
| Support найден | 2% | 1% |
| Close < Support | 0.5% | 1.5% |
| Score >= 50 | **0.3%** | 0.2% |

**Итого**: ~3 сигнала из 1000 свечей (очень строгая фильтрация).

## Скоринговая модель

### Зачем нужен Score?

Score позволяет **ранжировать сигналы** по качеству. Не все пробои одинаково надёжны.

### Таблица скоринга

| Фактор | Условие | Баллы | Макс |
|--------|---------|-------|------|
| **Слабость RS** | RS < -3% | +30 | |
| | RS < -5% | +10 | 40 |
| **Объём** | Volume >= 1.5x | +10 | |
| | Volume >= 2.0x | +10 | |
| | Volume >= 3.0x | +10 | 30 |
| **Возраст уровня** | Support age > 20 мин | +20 | 20 |
| **Funding** | Funding > 0.01% | +20 | 20 |
| **Close Position** | Close < 10% свечи | +10 | 10 |
| **Дивергенция** | BTC↑ и Актив↓ | +10 | 10 |
| | | | |
| **МАКСИМУМ** | | | **100** |

### Пример расчёта Score

```
Дано:
- RS = -4.2%
- Volume Ratio = 2.3x
- Support Age = 35 минут
- Funding Rate = 0.005%
- Close Position = 0.08 (8%)
- BTC за последнюю свечу: +0.3%
- Актив за последнюю свечу: -0.5%

Расчёт:
┌─────────────────────────────────────────┐
│ RS < -3%?           ✅  → +30           │
│ RS < -5%?           ❌  → +0            │
│ Volume >= 1.5x?     ✅  → +10           │
│ Volume >= 2.0x?     ✅  → +10           │
│ Volume >= 3.0x?     ❌  → +0            │
│ Age > 20 мин?       ✅  → +20           │
│ Funding > 0.01%?    ❌  → +0            │
│ Close < 10%?        ✅  → +10           │
│ BTC↑ и Актив↓?      ✅  → +10           │
├─────────────────────────────────────────┤
│ ИТОГО:                    90 баллов     │
└─────────────────────────────────────────┘

→ Score = 90 (Высокая вероятность падения)
```

### Интерпретация Score

| Score | Вероятность | Рекомендация |
|-------|-------------|--------------|
| 80-100 | Высокая | Агрессивный вход, можно увеличить размер |
| 60-79 | Средняя | Стандартный вход |
| 50-59 | Умеренная | Консервативный вход, меньший размер |
| < 50 | Низкая | **Сигнал отбрасывается** |

## Риск-менеджмент

### Размер позиции

#### Формула расчёта

```
Размер позиции = (Депозит × Риск на сделку) / (Цена входа × Стоп-лосс %)
```

#### Пример

```
Дано:
- Депозит: $10,000
- Риск на сделку: 1% ($100)
- Цена входа (шорт): $140.00
- Стоп-лосс: 1.5% выше входа = $142.10

Расчёт:
Размер = $100 / ($140 × 0.015) = $100 / $2.10 = 47.6 монет

Или в долларах: 47.6 × $140 = $6,664 (66% депозита с плечом 1x)
```

### Стоп-лосс

#### Где ставить стоп?

```
Цена
  │
  │    ════════════════════ ← Пробитая поддержка (теперь сопротивление)
  │         ↑
  │         │ ATR буфер
  │         ↑
  │    ─────────────────── ← СТОП-ЛОСС
  │
  │    ─────────────────── ← Цена входа (Close пробойной свечи)
  │         │
  │         ↓
  │
```

#### Методы установки стопа

| Метод | Формула | Пример |
|-------|---------|--------|
| **Фиксированный %** | Вход + 1.5% | $140 → стоп $142.10 |
| **Над поддержкой** | Support + ATR | $140.80 + $0.50 = $141.30 |
| **Над High свечи** | High пробойной свечи + буфер | $142.50 + $0.20 = $142.70 |

**Рекомендация**: Используй стоп **над пробитой поддержкой** с буфером 0.3-0.5 ATR.

### Тейк-профит

#### Соотношение Risk/Reward

| R:R | Описание | Когда использовать |
|-----|----------|-------------------|
| 1:1 | Консервативный | Низкий Score (50-60) |
| 1:1.5 | Стандартный | Средний Score (60-80) |
| 1:2 | Агрессивный | Высокий Score (80+) |
| 1:3+ | Трейлинг | Очень сильный тренд |

#### Уровни тейк-профита

```
Цена
  │
  │    ─────────────────── ← СТОП-ЛОСС ($142.10)
  │    ════════════════════ ← Поддержка/Сопротивление ($140.80)
  │    ─────────────────── ← ВХОД ($140.00)
  │         │
  │         ↓ 1R
  │    - - - - - - - - - - ← TP1: Частичный тейк ($137.90)
  │         │
  │         ↓ 2R
  │    - - - - - - - - - - ← TP2: Основной тейк ($135.80)
  │         │
  │         ↓ 3R
  │    - - - - - - - - - - ← TP3: Бонусный тейк ($133.70)
  │
```

### Управление позицией

#### Частичное закрытие

```
Стратегия "3-этапный выход":

1. При достижении TP1 (1R):
   - Закрыть 30% позиции
   - Перенести стоп в безубыток

2. При достижении TP2 (2R):
   - Закрыть ещё 40% позиции
   - Перенести стоп на уровень TP1

3. Оставшиеся 30%:
   - Трейлинг-стоп или TP3
```

### Максимальные лимиты

| Параметр | Значение | Объяснение |
|----------|----------|------------|
| Риск на сделку | 1-2% | Максимум потерь на одну сделку |
| Открытых позиций | 3-5 | Не более 5 одновременных шортов |
| Дневной лимит потерь | 5% | Стоп-торговля при -5% за день |
| Коррелированные активы | 2 | Не более 2 активов из одного сектора |

## Ограничения и подводные камни

### Когда стратегия НЕ работает

#### 1. Сильный бычий рынок (Bull Run)

```
        BULL MARKET - ИЗБЕГАЙ ШОРТОВ
        
    │                          ╱
    │                        ╱
    │                      ╱
    │         ╱╲         ╱
    │       ╱    ╲     ╱
    │     ╱        ╲ ╱
    │   ╱            
    │ ╱              
    └──────────────────────────────
    
    Даже "слабые" активы растут!
    RS может быть -3%, но актив всё равно в плюсе.
```

**Признаки**: BTC делает новые ATH, Fear & Greed > 75, все альты растут.

**Решение**: Уменьшить размер позиций на 50% или не торговать.

#### 2. Низкая волатильность (боковик)

```
        БОКОВИК - МНОГО ЛОЖНЫХ ПРОБОЕВ
        
    │    ════════════════════════════
    │   ╱    ╲      ╱    ╲      ╱
    │  ╱      ╲    ╱      ╲    ╱
    │ ╱        ╲──╱        ╲──╱
    │════════════════════════════════
    │
    
    Цена пробивает поддержку и сразу возвращается.
```

**Признаки**: ATR сужается, объёмы падают, BTC в узком диапазоне.

**Решение**: Требовать Score >= 70 вместо 50.

#### 3. Новости и события

```
        НОВОСТНОЙ SPIKE
        
    │              │
    │              │ ← Неожиданная новость
    │    ╭───╮     │
    │   ╱     ╲    │
    │══════════════╪════ Support
    │              │╲
    │              │ ╲______ Ложный пробой
    │              │        ↗
    │              │   Разворот
    
    Short squeeze после негативной новости.
```

**Решение**: 
- Не торговать за 1 час до/после важных новостей
- Проверять экономический календарь
- Избегать торговли при FOMC, CPI, NFP

#### 4. Слишком сильная слабость (RS < -10%)

```
    Парадокс: Если актив упал на 15% за час,
    возможен технический отскок (dead cat bounce).
    
    Лучший RS для шорта: от -3% до -7%
    Опасный RS: < -10% (вероятен откат)
```

### Типичные ошибки

| Ошибка | Последствие | Решение |
|--------|-------------|---------|
| Шорт без стопа | Огромные убытки при squeeze | Всегда ставить стоп |
| Усреднение убыточной позиции | Увеличение потерь | Никогда не усреднять шорты |
| Игнорирование funding | Short squeeze | Проверять funding перед входом |
| Торговля на новостях | Непредсказуемость | Пропускать новостные дни |
| Слишком большой размер | Эмоциональные решения | Максимум 1-2% риска |

## Чеклист для торговли

### Перед поиском сетапа

- [ ] BTC не делает новые ATH
- [ ] Fear & Greed Index < 75
- [ ] Нет важных новостей в ближайший час
- [ ] Волатильность нормальная (не боковик)

### При появлении сигнала

- [ ] RS < -3%
- [ ] Volume Ratio >= 1.5x
- [ ] Close Position <= 30%
- [ ] Funding Rate >= -0.015%
- [ ] Support чётко определён
- [ ] Close < Support
- [ ] Score >= 50

### Перед входом в сделку

- [ ] Рассчитан размер позиции (макс 1-2% риска)
- [ ] Определён стоп-лосс (над поддержкой + буфер)
- [ ] Определены уровни тейк-профита
- [ ] Нет других открытых позиций на этом активе
- [ ] Не превышен лимит открытых позиций (макс 5)

### После входа

- [ ] Стоп-лосс выставлен
- [ ] При достижении TP1 — частичное закрытие
- [ ] Стоп перенесён в безубыток
- [ ] Записана сделка в журнал

## Заключение

### Ключевые принципы стратегии

1. **Следуй за слабостью** — шорти то, что слабее рынка
2. **Подтверждай объёмом** — пробой без объёма ненадёжен
3. **Защищайся от squeeze** — следи за funding rate
4. **Качество > количество** — лучше меньше сделок, но качественных
5. **Управляй риском** — стоп-лосс обязателен

### Путь обучения

1. **Неделя 1-2**: Изучи теорию, смотри графики без торговли
2. **Неделя 3-4**: Paper trading (виртуальные деньги)
3. **Месяц 2**: Минимальные позиции ($10-50)
4. **Месяц 3+**: Постепенное увеличение при позитивной статистике

### Метрики для отслеживания

| Метрика | Цель | Как измерять |
|---------|------|--------------|
| Win Rate | 40-50% | Прибыльные / Все сделки |
| Avg R:R | 1.5+ | Средняя прибыль / Средний убыток |
| Profit Factor | 1.5+ | Сумма прибыли / Сумма убытков |
| Max Drawdown | < 15% | Макс просадка от пика |
