## Фаза 3: Pipeline фильтрации

### analyzeBreakdown() — 12 последовательных фильтров

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    SIGNAL FILTERING PIPELINE (v1.8.0)                        │
│                                                                              │
│                         Принцип: FAIL FAST                                   │
│                  (дешёвые проверки → дорогие проверки)                       │
└─────────────────────────────────────────────────────────────────────────────┘

                              ┌──────────────┐
                              │  NEW CANDLE  │
                              │   RECEIVED   │
                              └──────┬───────┘
                                     │
        ┌────────────────────────────┼────────────────────────────┐
        │                            │                            │
        │                            ▼                            │
        │    ┌──────────────────────────────────────────────┐    │
        │    │  FILTER 1: Volatility (v1.3.0)               │    │
        │    │                                              │    │
        │    │  NDR = (High24h - Low24h) / Price            │    │
        │    │                                              │    │
        │    │  NDR < 3% ? ──────────────────────────────▶ REJECT │
        │    │            "Dead coin, too stable"          │    │
        │    └──────────────────────────────────────────────┘    │
        │                            │ PASS                      │
        │                            ▼                            │
        │    ┌──────────────────────────────────────────────┐    │
        │    │  FILTER 2: Oversold 24h (v1.8.0) ⭐ NEW      │    │
        │    │                                              │    │
        │    │  Price24hPcnt < -15% ? ───────────────────▶ REJECT │
        │    │            "Already crashed, bear trap risk"│    │
        │    └──────────────────────────────────────────────┘    │
        │                            │ PASS                      │
        │                            ▼                            │
        │    ┌──────────────────────────────────────────────┐    │
        │    │  FILTER 3: Max Pump (v1.5.0)                 │    │
        │    │                                              │    │
        │    │  Price24hPcnt > 30% ? ────────────────────▶ REJECT │
        │    │            "Pumping too hard"               │    │
        │    └──────────────────────────────────────────────┘    │
        │                            │ PASS                      │
        │                            ▼                            │
        │    ┌──────────────────────────────────────────────┐    │
        │    │  FILTER 4: Smart Pump Near High (v1.5.0)     │    │
        │    │                                              │    │
        │    │  Pump > 15% AND distFromHigh < 3% ? ──────▶ REJECT │
        │    │            "Knife catching"                 │    │
        │    └──────────────────────────────────────────────┘    │
        │                            │ PASS                      │
        │                            ▼                            │
        │    ┌──────────────────────────────────────────────┐    │
        │    │  FILTER 5: MA Extension (v1.8.0) ⭐ NEW      │    │
        │    │                                              │    │
        │    │  SMA200 = avg(last 200 closes)               │    │
        │    │  Deviation = (SMA200 - Price) / SMA200       │    │
        │    │                                              │    │
        │    │  Deviation > 4% ? ────────────────────────▶ REJECT │
        │    │            "Rubber band risk"               │    │
        │    └──────────────────────────────────────────────┘    │
        │                            │ PASS                      │
        │                            ▼                            │
        │    ┌──────────────────────────────────────────────┐    │
        │    │  FILTER 6: OI Long Exit (v1.5.0)             │    │
        │    │                                              │    │
        │    │  Price ↓ AND OI ↓ (>2%) ? ────────────────▶ REJECT │
        │    │            "Longs exiting, not short opp"   │    │
        │    └──────────────────────────────────────────────┘    │
        │                            │ PASS                      │
        │                            ▼                            │
        │    ┌──────────────────────────────────────────────┐    │
        │    │  FILTER 7: Relative Strength (RS)            │    │
        │    │                                              │    │
        │    │  RS = AssetChange% - BTCChange% (1h)         │    │
        │    │                                              │    │
        │    │  RS >= -3% ? ─────────────────────────────▶ REJECT │
        │    │            "Not weak enough vs BTC"         │    │
        │    └──────────────────────────────────────────────┘    │
        │                            │ PASS (RS < -3%)            │
        │                            ▼                            │
        │    ┌──────────────────────────────────────────────┐    │
        │    │  FILTER 8: Funding Rate (Anti-Squeeze)       │    │
        │    │                                              │    │
        │    │  FundingRate < -0.015% ? ─────────────────▶ REJECT │
        │    │            "Crowded short, squeeze risk"    │    │
        │    └──────────────────────────────────────────────┘    │
        │                            │ PASS                      │
        │                            ▼                            │
        │    ┌──────────────────────────────────────────────┐    │
        │    │  FILTER 9: Volume Ratio                      │    │
        │    │                                              │    │
        │    │  VolumeRatio = CurrentVol / AvgVol(20)       │    │
        │    │                                              │    │
        │    │  VolumeRatio < 1.5x ? ────────────────────▶ REJECT │
        │    │            "Weak volume, no conviction"     │    │
        │    └──────────────────────────────────────────────┘    │
        │                            │ PASS                      │
        │                            ▼                            │
        │    ┌──────────────────────────────────────────────┐    │
        │    │  FILTER 10: Close Position (Wick Check)      │    │
        │    │                                              │    │
        │    │  ClosePos = (Close - Low) / (High - Low)     │    │
        │    │                                              │    │
        │    │  ClosePos > 30% ? ────────────────────────▶ REJECT │
        │    │            "Buyback detected"               │    │
        │    └──────────────────────────────────────────────┘    │
        │                            │ PASS                      │
        │                            ▼                            │
        │    ┌──────────────────────────────────────────────┐    │
        │    │  FILTER 11: Support Detection                │    │
        │    │                                              │    │
        │    │  1. Try: Consolidation zone (range <3%)      │    │
        │    │  2. Fallback: Fractal Low pattern            │    │
        │    │                                              │    │
        │    │  No support found ? ──────────────────────▶ REJECT │
        │    └──────────────────────────────────────────────┘    │
        │                            │ PASS                      │
        │                            ▼                            │
        │    ┌──────────────────────────────────────────────┐    │
        │    │  FILTER 12: Dynamic Support Age (v1.8.0)⭐NEW│    │
        │    │                                              │    │
        │    │  Change1h = price change over last 60 min    │    │
        │    │                                              │    │
        │    │  ┌─────────────────────────────────────────┐ │    │
        │    │  │ IF Change1h < -2% (high volatility):    │ │    │
        │    │  │    minAge = 45 minutes                  │ │    │
        │    │  │ ELSE:                                   │ │    │
        │    │  │    minAge = 15 minutes                  │ │    │

        │    │                                              │    │
        │    │  SupportAge < minAge ? ───────────────────▶ REJECT │
        │    │            "Support too young"              │    │
        │    └──────────────────────────────────────────────┘    │
        │                            │ PASS                      │
        │                            ▼                            │
        │    ┌──────────────────────────────────────────────┐    │
        │    │  CHECK: Breakdown Condition                  │    │
        │    │                                              │    │
        │    │  Close >= Support ? ──────────────────────▶ REJECT │
        │    │            "No breakdown yet"               │    │
        │    └──────────────────────────────────────────────┘    │
        │                            │ PASS (Close < Support)    │
        │                            ▼                            │
        │    ┌──────────────────────────────────────────────┐    │
        │    │  CHECK: No Bounceback                        │    │
        │    │                                              │    │
        │    │  Wick above support? ─────────────────────▶ REJECT │
        │    │            "Bounceback detected"            │    │
        │    └──────────────────────────────────────────────┘    │
        │                            │ PASS                      │
        │                            ▼                            │
        └────────────────────────────┼────────────────────────────┘
                                     │
                              ┌──────┴───────┐
                              │   SCORING    │
                              │   PHASE      │
                              └──────────────┘
```
